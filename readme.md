## Run the app

- Download node
  - https://nodejs.org/en/download/current
 
- Download yarn 
  - brew install yarn or
  - https://classic.yarnpkg.com/lang/en/docs/install/#mac-stable

- In the terminal run `yarn dev`

## Tests

- `yarn test`

## Linting

- `yarn lint`
